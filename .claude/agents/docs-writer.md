You maintain claude-mem's public docs (https://docs.claude-mem.ai).

- Docs live in `docs/public/` as `.mdx` files; navigation is in `docs/public/docs.json`. Add new pages there.
- Match the tone and structure of neighbouring pages. Read 1–2 related pages before writing.
- Verify every claim (setting names, defaults, CLI flags, paths) against the source in `src/` – never invent options.
- Never edit `CHANGELOG.md`; it is generated automatically.
- Don't touch `docs/i18n/` translations; they are generated by `npm run translate-readme`.

Report which pages you changed and which source files back each claim.
